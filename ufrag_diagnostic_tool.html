🚨 Error Analysis: "Unknown ufrag (22021986)"

What is this error?

  • Ufrag = "Username Fragment" - a unique identifier for WebRTC ICE sessions
  • "Unknown ufrag" = ICE candidate received for a session that no longer exists
  • Root cause = Stale ICE candidates being processed after connection reset
Example Ufrag in ICE Candidate:
candidate:1 1 UDP 2113667326 192.168.1.100 54321 typ host ufrag 22021986
↑ This ufrag "22021986" doesn't match current connection

✅ Applied Fixes

1. Enhanced ICE Candidate Validation

  • Connection Version Tracking: Each connection has a unique version number
  • Ufrag Validation: Validates ICE candidate format before processing
  • State Validation: Checks connection and signaling states
  • Stale Candidate Detection: Rejects candidates from old connections

2. Persistent Error Recovery

  • Error Counting: Tracks repeated ufrag errors per peer
  • Automatic Reset: Resets connection after 3 consecutive errors
  • Graceful Reconnection: Waits 2 seconds before retry
  • Clean State Management: Proper connection cleanup
