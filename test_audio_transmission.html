🧪 Audio Troubleshooting

❌ Common Issues & Solutions

Issue: "No Audio" status for remote participants

  • Cause: Audio tracks not properly added to peer connections
  • Solution: Fixed in handlePeerJoined() to automatically start audio
  • Check: Console should show "🎵 Adding track: audio (enabled: true)"

Issue: Audio works initially but stops after peer joins

  • Cause: Track renegotiation not triggered properly
  • Solution: Added automatic renegotiation in startAudio()
  • Check: Console should show "🔄 Triggering renegotiation for [peer_id]"

Issue: ICE connection fails

  • Cause: TURN server issues or firewall blocking
  • Solution: Added multiple TURN servers in WebRTC config
  • Check: Console should show "✅ Successfully connected to [peer_id]"
